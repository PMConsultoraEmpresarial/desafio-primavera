# Desafío Primavera

Aplicación web de una dinámica de trabajo colaborativo de 12 minutos.
Corre íntegramente en el navegador: no tiene servidor, no envía datos a ninguna
parte y no recolecta información de las personas que participan.

La empresa, las consultoras y los datos del caso son ficticios.
